# 项目深度优化清单

> 基于 2026-09-11 对当前前后端源码、配置、SQL、构建脚本和测试目录的审阅。编号同时对应同目录下的实施方案文档。

| 编号 | 优化主题 | 优先级 | 主要影响 |
|---|---|---|---|
| 01 | [安全配置与密钥治理](./01_plan.md) | P0 | 默认密钥、数据库密码、SQL 日志和生产配置暴露风险 |
| 02 | [统一认证与会话生命周期](./02_plan.md) | P0 | 前端 localStorage 守卫、JWT 失效、退出和刷新机制不完整 |
| 03 | [API 权限与接口契约统一](./03_plan.md) | P0 | 公告路径复数不一致、非 REST 路径、权限矩阵漂移 |
| 04 | [订单状态机与交易一致性](./04_plan.md) | P0 | 模拟支付、状态越权、库存并发和幂等性不足 |
| 05 | [文件上传与对象存储治理](./05_plan.md) | P1 | 文件校验、资源访问、失败补偿和配置依赖需要强化 |
| 06 | [聊天与 WebSocket 可靠性](./06_plan.md) | P1 | Origin 放开、连接生命周期、消息聚合和可观测性不足 |
| 07 | [数据访问与数据库性能](./07_plan.md) | P1 | 全量联系人聚合、热点查询无缓存、表名和索引治理不足 |
| 08 | [前端构建、类型与依赖治理](./08_plan.md) | P0 | `npm run build` 失败、包管理器不统一、类型债务积累 |
| 09 | [测试体系与持续集成](./09_plan.md) | P1 | Controller、集成、WebSocket、权限和前端测试覆盖不足 |
| 10 | [部署、配置与运行观测](./10_plan.md) | P1 | 环境差异、健康检查、日志指标、备份和发布回滚不完整 |

## 推荐实施顺序

1. 01、02、03：先关闭可直接导致越权、泄密或接口不可用的风险。
2. 04、05、06、07：再治理交易、文件、实时通信和数据库的核心运行链路。
3. 08、09：恢复可重复构建并建立回归保护网。
4. 10：最后补齐部署、观测、备份和回滚能力，形成上线闭环。

## 使用说明

每份方案均包含现状证据、目标、实施步骤、改动边界、验收标准、风险与回滚策略。方案是实施设计，不代表对应代码已经修改完成。
